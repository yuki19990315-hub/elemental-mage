# Elemental Mage — 8属性／新モンスター対応試作 v3

## 今回の実装（2026-11-10）

- `prototype/game.js` は `data/elements.json`、`data/fusion_recipes.json`、`data/enemies.json`、`data/bosses.json` の読み込みに対応。オフライン時の最低限の代替定義も保持。
- 無属性から開始し、第1階層の祭壇で最初の属性を選択する。装備枠は2枠。拾った魔導石で入れ替える。ボス直前には2択の報酬を必須配置。
- 炎、水、氷、雷、風、土、光、闇の個別攻撃動作を試作用に実装。異なる属性が2つ揃うと合成ボタンを利用可能。全28組のうち設計未確定のものは、汎用的な試作エフェクトを使用する。
- 新しい5敵の行動を実装：ポイズンスライム（赤い突進予告線・障害物衝突STUN）、蒼氷の結晶体（壁反射弾）、深淵の魔眼（追尾電撃）、光輝の使徒（予告付き聖光線）、深淵の彷徨者（突進と闇弾）。
- ボスの弾幕を差別化。炎の巨人は火球・火床、氷晶の女王は反射氷弾、深淵の魔眼は円形弾幕と追尾電撃。
- `assets/sprites/v2` の透過PNGアニメーションを優先表示。素材の読み込みに失敗したときだけ従来SVGにフォールバックする。
- `prototype/logic.js` に属性ペア、線分と障害物の衝突、追尾弾の旋回などの計算を分離し、Nodeテスト可能にした。

## プレイ方法

```bash
python -m http.server 8000
# http://localhost:8000/prototype/
```

スマホでは左下の仮想スティック、右下の3ボタン。PCではWASDまたは矢印キー、J/K/L。

## 残課題と制約

- 部屋の構造は現在も単純な3戦闘部屋＋ボスの試作です。正式なプロシージャル接続・階層間の探索分岐は未実装。
- 被弾、気絶、弾幕、攻撃倍率、効果時間等の数値は仮値。新敵やボスのAIは初期の挙動実装であって完成版ではない。
- 自動生成したPNGは画面拡大時の透明ノイズやフレーム間のズレが残る可能性があり、ゲーム内での最終視覚確認が必要。
- スマホ実機のパフォーマンス／操作性の計測、APK化は未実施。
