# Elemental Mage ゲーム企画・仕様書 v1.0

## 企画概要
**スマートフォン縦画面専用・2D見下ろし型・属性合成ローグライト弾幕アクション。**
プレイヤーは魔法使いを操作し、ランダム生成された部屋を攻略。2属性の魔導石を装備して個別の魔法と合成魔法を使用し、弾幕を避けて複数階層のボスを倒す。

> 「確定」はユーザーが指定した仕様、「提案」は後から変更できる初期実装案。

## 確定した操作仕様
- 縦持ちスマートフォン向け。左下の半透明バーチャルジョイスティックで移動。
- 右下に半透明の攻撃ボタン3つを設置。装備属性1、装備属性2、合成魔法をそれぞれ発動。
- ボタン上には装備属性を示すアイコンを表示する。
- 攻撃は主人公が向いている方向に発射。初期試作は移動方向に旋回し、停止時は最後の向きを保持。
- 敵が画面内の複数地点から出現し、弾幕を撃つ。
- 属性アイテムは2個同時装備。ドロップした装備を拾い、装備枠と交換可能。
- ボス部屋の直前には2個のアイテムを提示し、必ず1個だけ選択。
- ダンジョンは階層または部屋遷移で進行し、部屋の構造をランダム化。
- ボスは複数種類。あらゆるコンテンツを後から追加できる構造とする。

## 戦闘・弾幕
敵弾は直線、狙い撃ち、扇、円形、らせん、追尾、反射、レーザーを共通パターンとして定義する。
危険予告・視認性・回避可能な隙間を優先する。大量弾はオブジェクトプーリングで再利用。ダメージ判定と描画サイズを区別できるようにする。

## 属性・魔法（初期案）
炎・水・氷・雷・風・土の6属性。
炎＝燃焼・範囲、水＝貫通・押し戻し、氷＝減速・凍結、雷＝連鎖・高速、風＝拡散・多段、土＝防御・破砕。
各属性の装備タイプは将来的に火球、放射、爆発、剣など複数に増やす。通常魔法と合成魔法は別クールタイムを持つ。
異なる2属性の15組に、固有の合成魔法を割り当てる。順序が違っても同じ組み合わせを認識する。
連続的に異なる属性を当てた場合の状態異常連携は追加案とする。

## ダンジョン（初期案）
各フロアは5〜7部屋程度から開始し、接続グラフ・テンプレート・障害物・敵出現位置・報酬を乱数シードから生成する。
部屋は通常戦闘、大群戦闘、宝箱、回復、エリート、イベント、隠し部屋、ボス直前報酬、ボス。
スタートからボスへの到達可能性を保証し、ボス直前の2択報酬は必ず経路上に配置する。
探索済みの部屋へ戻れる案。敵撃破で扉が開く。階層ごとに難易度・地形テーマを調整。

## 敵（初期案）
- スライム：接近、分裂、突進。
- 魔眼：狙い撃ち、追尾弾。
- 魔導師：扇状、円形弾幕。
- 結晶体：レーザー、反射弾。
- コウモリ：素早い接近と散弾。
- ゴーレム：遅い重装、衝撃波。
属性による弱点・耐性は実装段階で数値を調整。

## ボス（初期案）
- **灼熱の巨人**：巨大火球と溶岩の床。HP減少で攻撃頻度上昇。
- **氷晶の女王**：氷弾、床の凍結、分身召喚。
- **深淵の魔眼**：円弾、追尾弾、回転レーザー、複数フェーズ。
予告動作と回避余地は必須。

## 報酬・進化
属性魔導石、攻撃強化、回復、リスク付きの呪いアイテムなど。拾ったアイテムはその場で装備または交換。
同属性の重複獲得による魔法進化・永続アンロック・隠し部屋・追加属性・追加ボスは段階的に実装。

## プレイサイクル
入場 → 部屋の探索・戦闘 → ドロップ・装備交換 → ボス前の2択 → ボス撃破 → 次の階層。
HP0で探索終了。永続強化・引き継ぎ仕様は未決定。

## ビジュアル
暗めのファンタジー背景に明るい魔法エフェクト。小さな親しみやすいドット絵魔法使い、敵、遮蔽物、属性弾。背景4テーマ（石・溶岩・氷・苔）は初期アート案。
視認性と片手幅の操作領域を優先し、UIは画面下端にまとめる。

## 完了条件（MVP）
1. 縦画面で移動・向き依存攻撃・3ボタンが動く。
2. 属性2枠の装備・交換と合成魔法を実行できる。
3. 敵の弾幕・ダメージ・ゲームオーバーが機能する。
4. 複数部屋をランダム生成しボス前2択からボス戦まで進行できる。
5. データ変更で敵・魔法・ボス・部屋を追加できる。
6. Android実機で動作と視認性を確認する。
