# ゲームデータと素材参照の整合性修正（2026-11-10）

## 更新したもの
- `data/elements.json`: 無属性 + 8属性。旧 `lightning` IDを維持し表示上の雷（Thunder）との別名対応を記載。
- `data/fusion_recipes.json`: 8属性の異なる2属性ペア28組を一意に定義。旧15レシピと新13レシピを区別。効果が決まっていないものは明示的に設計中。
- `data/enemies.json`: 既存6種に5種追加。アイテム画像と実装候補スプライトを混同せず、`asset` / `spritePack` に別々に持つ。
- `data/bosses.json`: 既存ボスIDを維持し、v2スプライト候補の参照を追記。
- `tools/validate.py`: データ重複、28組の網羅、画像参照、SVG形式、素材パケットのパスとPNG署名を確認。

## 確認すべき実装上の課題
1. 試作版UI/攻撃処理は6属性に固定されており、9種類のデータを読み込む機能は未実装。
2. 新しい敵のAIはデザイン仕様のみ。予測線、壁衝突STUN、反射弾、光条、螺旋弾幕は未実装。
3. v2スプライトのPNGはリポジトリ内の画像候補と復元用パケットの数が一致するか確認が必要。確認できていないPNGを実装済み扱いしない。
4. 敵の当たり判定、各攻撃フェーズやバランス数値は、アートから自動決定しない。

## アートデータについて
`assets/concepts` はコンセプト画。既存 `assets/enemies` / `assets/bosses` は試作版の互換用アートです。
`assets/sprites/v2` は高精細候補アートの実装向け出力先です。移行時は候補の目視確認を必須とします。
