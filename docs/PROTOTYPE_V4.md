# Elemental Mage — 戦闘システム v4（試作）

## 新たに動作を追加したギミック

- **魔力吸収**：土・闇などの弾消しで敵弾を吸収し魔力ゲージが溜まる。40以上で合成魔法が自動強化。
- **地形反応**：水で濡れた地点に雷を当てると感電床、氷なら氷床、炎なら蒸気床になる。
- **魔法の突然変異**：最初の戦闘部屋クリア後に3択の強化画面。威力・速度・貫通・HP・精霊・魔力吸収を選べる。
- **ボス部位破壊**：ボスの左右に小さい弱点。破壊すると本体HPが減り、攻撃の間隔に一時的な隙が生まれる。
- **呪われた祭壇**：2階層目以降、部屋2の後で最大HPを犠牲に魔法威力を上げるか選択する。
- **敵の巻き込み**：敵弾が別の敵に当たるとダメージを与える。
- **分岐ルート**：ボス撃破後に回復ルートか敵増加ルートを選ぶ。
- **精霊召喚**：突然変異「精霊契約」で補助攻撃する小型精霊が出現。
- **魔法熟練**：同じ属性の通常魔法を25回発射すると威力・演出が強化される（現状は簡易表現）。

## アートと構造

5テーマの新背景と12種類の透過障害物は `assets/environment/v2` を優先して表示し、読み込み前は従来の画像へフォールバックする。
`prototype/mechanics_v4.js` は純粋な計算をまとめた共有モジュールで、`node tools/test_mechanics_v4.js` で検証可能。

**現状はブラウザ試作の簡易挙動です。** ルート分岐は実際のダンジョン分岐マップではなく難易度の選択です。弱点部位は簡易円形当たり判定。属性地形は全属性組み合わせを完全再現したものではありません。ゲームバランス、アニメーションとモバイル実機テストは未完了。
