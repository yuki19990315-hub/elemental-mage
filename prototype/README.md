# ブラウザ試作版

## 起動
リポジトリ直下で `python -m http.server 8000` を実行し、`http://localhost:8000/prototype/` を開く。GitHub Pagesを有効化して静的配信することも可能。

## 操作
- 画面左下の半透明ジョイスティックをドラッグして移動（向きは最後の移動方向を保持）。
- 画面右下：属性魔法1、属性魔法2、合成魔法を長押し可能。
- PC：WASDまたは矢印、J/K/L。
- 通常の3部屋を撃破するとボス直前の報酬2択が出現し、選んだ属性を装備枠1か2と交換。ボス撃破で次階層。
- HPゼロでゲームオーバー。画面タップで再挑戦。

## 範囲
ゲーム企画の一部を操作検証する技術試作。ダンジョングラフ全体の生成、全15合成の固有挙動、永続成長、セーブ、APK化は未実装。背景とキャラクターはGitHub版SVGアセットを参照する。
