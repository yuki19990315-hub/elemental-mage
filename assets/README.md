# 画像アセット（SVG）
画像は個別のオリジナルSVG。ドット絵風の設定画・スターター素材で、編集やリサイズが可能です。
- [素材一覧](previews/asset_catalog.svg)
- [15種類の合成魔法](previews/fusion_catalog.svg)
- [縦画面のUIイメージ](previews/mobile_mockup.svg)
- characters: 魔法使い4方向×2コマ（8枚）
- enemies: 6種類×2コマ（12枚）
- bosses: 3種類
- tiles: 4テーマの床×4バリエーションと壁（20枚）
- obstacles: 6種類
- projectiles: 属性弾12枚、敵弾6枚、合成弾15枚
- icons: 6属性
元の配布ZIPに収録した透過PNGとは別の、GitHub向け独立SVGデータです。双方の完全一致は保証していません。
