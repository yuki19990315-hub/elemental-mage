# モバイルUI リデザイン・実装 v5

## 今回の実装
以前生成した『Elemental Mage モバイルアプリ UI/UX デザインコンセプトボード』を基準に、既存のGBA規格素材を利用してブラウザ試作版の画面構成を更新しました。**デザインボードはイメージ資料であり、各画面のピクセル単位の完全再現ではありません。** 詳細な背景やメニュー演出はWeb/CSSの表現です。

[装飾フレームSVG](../assets/ui/v1/panel_frame.svg) · [ボタンフレームSVG](../assets/ui/v1/action_button.svg)

### 画面と操作
| 画面 | 実装内容 | 備考 |
|---|---|---|
| ホーム | 主人公、開始、続きから、図鑑への導線 | ページ離脱中のランは保持。再読み込み時の続きからは未対応 |
| バトル | 既存の縦画面ゲーム、3つの攻撃ボタン、停止メニュー | 戦闘処理は既存キャンバス |
| 装備 | 2つの装備枠切り替え、取得済み属性石の装備 | 新しい石はバトル内で取得 |
| モンスター図鑑 | 通常6・上位5・ボス3の一覧、個別詳細 | 発見・討伐履歴の保存は未対応 |
| 強化 | 変異6種の一覧・試作適用 | 強化の自由適用は**デバッグ用** |
| 召喚 | 精霊のランダム表示デモ | 課金・ガチャ・永続所持はなし |
| 所持品 | 入手属性石の一覧、装備画面への移動 | 消費アイテムは未対応 |
| 設定 | UI効果削減、メニュー文字拡大 | ブラウザのローカル保存 |
| プロフィール | 現在のランのHP・階層・使用回数など | オンラインアカウントなし |
| ミッション | 現在のランの利用状況を使った進行表示 | 報酬配布は未対応 |
| メニュー | 各種画面への導線、探索へ復帰 | 既存戦闘状態の保持 |

### 実装ファイル
- \`prototype/index.html\`: アプリシェル、画面枠、ナビゲーション、canvasを保持
- \`prototype/style.css\`: ダークファンタジー配色、金縁、画面比率、レスポンシブ配置
- \`prototype/ui.js\`: 画面遷移・装備・図鑑・設定・表示専用の状態管理
- \`prototype/game.js\`: UIとの連携API、取得済み装備管理、一時停止処理
- \`tools/test_app_shell.js\`: UIをDOMモックで操作する自動テスト
- \`assets/ui/v1/\`: UIのデザイン資料・SVGパーツ

### 重要な注意
- UIの高精細発光装飾はCSS・SVGであり、**ゲーム内の16色キャラクター素材の規格を変更していません。**
- 初回の属性選択やボス前の2択などは従来通りゲーム画面内の操作です。
- GitHub Pagesが未設定なら公開できません。ビルド成功とWeb公開成功は異なります。
- システム全画面の操作性はブラウザ試作段階です。スマホ実機の画面サイズ・タッチの最終検査、APK作成、セーブ・ショップ・本番ガチャは未実装です。
